Things I've built.

Tools for file storage, offline browsing, and chat.

CloudKeep

A file manager for your own Cloudflare R2 or MinIO storage, built with Django and React.

Files transfer directly between browser and storage via presigned URLs. The API verifies uploads before saving metadata. A browser queue handles retries and cancellation.

  • Django REST Framework
  • React
  • PostgreSQL
  • S3-compatible storage
GitHub ↗

Issue-Vault

Archives GitHub issues, labels, and conversations in SQLite and exports a portable HTML site for offline browsing.

Fetches issues and comments page by page. A separate renderer bundles data, CSS, and JavaScript for local search, state filters, and hash-based navigation.

  • Python
  • SQLite
  • JavaScript
  • GitHub REST API
Live demo ↗GitHub ↗

Sync-D

One-to-one chat with real-time messages, online presence, message history, and image sharing.

Express saves messages in MongoDB before sending Socket.IO events. React and Zustand manage chat state; JWT handles login and Cloudinary handles image uploads.

  • React
  • Zustand
  • Express
  • MongoDB
  • Socket.IO
